# Новый дизайн — исходники из Claude Design

Сюда положен прототип. **Это ещё не шаблоны приложения**, а макет,
который работает на своём движке (`support.js`).

## Что есть

| Файл прототипа | Станет шаблоном |
|---|---|
| `Login.dc.html` | `templates/login.html` |
| `NoAccess.dc.html` | `templates/no_access.html` |
| `Dashboard.dc.html` | `templates/index.html` |
| `Users.dc.html` | `templates/admin_users.html` |
| `Orders.dc.html` | `templates/orders.html` |

Экраны совпадают с приложением один в один — макет рисовался
поверх реальных текущих шаблонов (проверено: файлы в `uploads/`
исходного архива побайтово совпадают с `templates/`).

## Почему нельзя просто скопировать

1. Прототип написан на своём синтаксисе: `<x-dc>`, `sc-for`, `sc-if`,
   а данные подставляются как `{{ ... }}`.
2. **`{{ }}` — это ровно синтаксис Jinja2**, на котором работает приложение.
   Если положить эти файлы в `templates/` как есть, Jinja попытается
   их исполнить и страница упадёт.
3. В прототипе зашиты выдуманные данные (Jan Kowalski, 2834 заказа).
   Их надо заменить на настоящие поля из API.

Поэтому дизайн **переносится вручную**: берём вёрстку и стили,
выбрасываем движок прототипа, подключаем реальные данные.

## Что дизайн добавляет сверх текущего приложения

- **Переключатель PL / RU** — в приложении сейчас нет, нужен словарь переводов.
- **Тёмная тема** — тоже нет, нужны переменные цвета.
- Обе настройки прототип хранит в `localStorage` (`ekomat_lang`, `ekomat_theme`).
- Шрифты **IBM Plex Sans** и **IBM Plex Mono** (цифры моноширинные, с `tnum`).
  Сейчас приложение использует системный шрифт.
- На мобильном таблица заказов превращается в карточки.

Chart.js остаётся тот же — 4.4.1 с того же CDN, что и сейчас.

4. `index.html` (697) — дашборд, графики
5. `orders.html` (1547) — самый большой, оставляем напоследок

Делается это **на v2**, прод не трогаем.
